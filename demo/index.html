ARIA Announcements Demo

Use a screen reader or the extension's Announcements DevTools tab to explore announcements. Actual speech depends on the browser and assistive technology. Controls are outside the bordered live regions.

Live regions

Each region starts empty. Add content, update the last item, remove it, or clear the region. Settings apply to that region only; changing a setting does not itself add content.

aria-atomic controls whether the whole region is announced. aria-relevant selects which changes matter (removals are not included by default). Set aria-busy while making changes, then uncheck it to release the pending updates. "Default" leaves the attribute absent, preserving the role's implicit behavior.

ariaNotify

Announce without changing live-region content

Requires browser support for ariaNotify. Sending a notification does not change the target's text.

Element notification target (not a live region).
